# Домашнє завдання 2: Основні структури даних

Два незалежні завдання на використання `Queue` і `deque`.
Для запуску потрібен Python 3. Зовнішні бібліотеки встановлювати не потрібно.

## Завдання 1 — Черга заявок

```bash
python task_1.py
```

На кожному кроці програма автоматично створює заявку з унікальним номером,
додає її до `Queue` з модуля `queue` і обробляє найстарішу заявку.
Функції `generate_request()` та `process_request()` відповідають наданому
псевдокоду. Якщо черга порожня, `process_request()` виводить повідомлення.

Натисніть Enter для наступного кроку або введіть `q` для виходу.
Також можна завершити програму за допомогою Ctrl+C.

## Завдання 2 — Паліндром

```bash
python task_2.py
```

Функція `is_palindrome(text)` додає символи рядка до `deque` з модуля
`collections` після нормалізації регістру та видалення пробільних символів.
Далі вона порівнює символи з обох кінців черги за допомогою `popleft()`
і `pop()`, доки не залишиться нуль або один символ.

У Windows замість `python` можна використовувати `py`, а в Linux/macOS —
`python3`. Команди потрібно запускати з папки, у якій лежать файли завдань.
